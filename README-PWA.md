# Zero'X Store V3 — PWA

Versión móvil inspirada en la referencia roja/negra compartida por el usuario.

## Ejecutar localmente
```bash
npm install
npm start
```
Abre http://localhost:3000

## Incluye
- Diseño responsive rojo/negro.
- Catálogo de diamantes promocionales de 1 vez por ID e ilimitados.
- Selector de moneda MXN/USD/COP/ARS/BRL con conversión de referencia.
- Métodos de pago visuales: Binance, transferencia, depósito y PayPal.
- WhatsApp: +52 951 475 4210.
- Sección de revendedores preparada como roadmap.
- PWA instalable al publicarse bajo HTTPS.
- Panel administrativo existente en /admin.html.

## Importante
Los pagos y proveedores continúan en modo demo. Las conversiones de moneda son solo de referencia y deben conectarse a tipos de cambio/pasarelas reales para producción.
